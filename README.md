# Shivamani — Interactive Portfolio

A responsive single-page portfolio built from the uploaded portfolio hero guide and resume.

## Included
- Interactive left / center / right hero cursor zones
- Developer-at-laptop visual built with HTML/CSS (no external image required)
- About, experience, projects, skills, education, certifications and contact sections
- Responsive desktop/tablet/mobile layout
- Direct email, phone, LinkedIn and GitHub links

## Run
Open `index.html` in a browser.

For the full interactive experience during development, use VS Code + Live Server.
